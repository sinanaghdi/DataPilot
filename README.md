# Sina Naqdi — Data Analyst Portfolio

A personal, bilingual portfolio focused on making data analysis and business intelligence easy to understand.

## Portfolio experience

- Clear introduction to the kinds of business questions I work on
- Three simple areas of focus: business performance, customer behavior, and market analysis
- Four visual project stories: RetailSignal, BaSalam Analytics, Customer Churn, and Sahmino
- Short project explanations covering the question, analysis, outcome, data scale, and tools
- Skills shown in plain language
- English and Persian language switch
- Responsive layout for desktop and mobile

## Built with

Plain HTML, CSS and JavaScript. No React, build step, charting package, or code-view interface is required.

## Files

- `index.html`
- `portfolio.css`
- `portfolio.js`
- `portfolio-icon.svg`

## Publish with GitHub Pages

In **Settings → Pages**:

1. Set Source to **Deploy from a branch**.
2. Select branch **portfolio-pages**.
3. Select folder **/(root)**.
4. Save.

Expected project URL: https://sinanaghdi.github.io/DataPilot/
