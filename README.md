# Sina Naqdi — Data Analyst Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript.

## Site files

- `index.html` — portfolio page and metadata
- `portfolio.css` — responsive styling, light/dark themes and print styles
- `portfolio.js` — project details, bilingual UI, skills filters, interactive case-study tabs, Bayesian rating simulator, Sahmino scenario selector and ATS resume actions
- `portfolio-icon.svg` — favicon

## Enable GitHub Pages

In the repository settings:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select branch **portfolio-pages** and folder **/(root)**.
4. Save the settings.

The project site URL will be:

https://sinanaghdi.github.io/DataPilot/
